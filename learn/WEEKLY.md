# 週1回：AIの新しい機能の提案（学習キット）

毎週月曜 10:13（日本時間）に Claude Code の定期タスクがこの手順で動く。**作るのは承認後。**

1. 社内のAI週報は見つかっていない（2026年11月1日に Gmail・Notion を確認）。
   そのため **週1回だけ、公式の発表を確かめる**：
   - https://www.anthropic.com/news
   - https://docs.anthropic.com/en/release-notes/overview
   - https://docs.claude.com/en/release-notes/claude-code
   読めない（つながらない）ときは、何もせずに終わる。推測で書かない。
2. その週（直近7日）の新機能から、**このリポジトリのアプリ（商品データベース・現場チェック）で使えるもの**を
   最大2件選ぶ。当てはまるものが無い週は **何も書かず、何も送らない**。
3. `learn/ai-proposals.md` の末尾に「AI提案 No.」を続き番号で付けて書く：
   どのアプリに／使う人にとって何が良くなるか／使う機能と出典（URL）／費用／危ないこと／作る手間
4. 新しい機能は自動では入れない。提案の要旨だけを持ち主に知らせる。
   持ち主が「AI提案 No.○ OK」と言ったものだけ、別の作業で作る。
5. `learn/LEARNING.md` は読んでよいが、`learn/latest.json` 以外の記録やリポジトリ全体は読まない。
